Nationwide Building Society — API orchestration architecture

Led a team of 5 engineers in designing and architecting API orchestration services for Business Banking, connecting cloud-hosted .NET 10/C# services with legacy on-premises WCF services.

Challenge

Connect modern cloud APIs with mission-critical legacy services while maintaining secure enterprise communication and a clear separation between cloud and on-premises responsibilities.

Architecture

Cloud API services → API orchestration layer → on-premises WCF services, with REST-based integration flows.

Leadership

Technical leadership for a 5-engineer team, including architecture decisions, engineering standards, design collaboration, and delivery planning.

Security

Keytab/Kerberos-based authentication for secure enterprise communication across the integration boundary.

.NET 10 · C# · AWS · Kubernetes · Azure DevOps CI/CD · REST APIs · WCF · Keytab/Kerberos
